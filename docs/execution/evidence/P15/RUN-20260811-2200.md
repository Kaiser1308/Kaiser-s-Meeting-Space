## Security and integrity evidence

- Translation input pins meeting mode, opposite language, source segment,
  projection version, revision, range, and SHA-256 source hash.
- API verifies owner/meeting/source ownership and recomputes the source hash
  before provider execution; it does not update source rows.
- Policy rejects meeting-only mode, incomplete P14 source state, owner
  mismatch, missing provider authorization/disclosure/budget, duplicate
  idempotency, and invalid language pairs before provider calls.
- Provider credentials are resolved from a server-side secret reference and
  never appear in result/error schemas, logs, client projections, or fixtures.
- Provider failures expose only safe error codes/message keys; raw payloads and
  source content are not copied into errors.
- `translation_versions` is append-only by PostgreSQL trigger; current pointer
  is separate and owner/meeting scoped. Migration is additive and contains no
  source mutation or DROP.
- Realtime translation is marked ephemeral/provisional and cannot become the
  authoritative current final; only a matching completed version is promoted.
