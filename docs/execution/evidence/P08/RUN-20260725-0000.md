### Preflight test-environment decision (recorded before T01)

The mobile vitest config previously included only `.test.ts` (no `.tsx`), had no React/React-Native test runtime, and `react-native` ships Flow source (`import typeof`) that vitest's rollup transform cannot parse. Switching mobile to jest/jest-expo would be a framework change (forbidden by the scope firewall without an ADR). Decided, within vitest:

- `apps/mobile/src/test-setup.ts` mocks `react-native` primitives (Text, View, TouchableOpacity, Pressable, SafeAreaView, ScrollView, TextInput, StatusBar, StyleSheet, Platform) and `expo-status-bar` so component modules load under vitest/node without parsing Flow.
- `apps/mobile/src/test-utils.tsx` provides a lightweight **custom element-tree renderer** (`render`, `resolve`, `findByType`, `findByProp`, `getText`, `press`) that evaluates presentational components (state via props, actions via callbacks) directly. This avoids React 19's deprecated `react-test-renderer` (concurrent-mode unmount issues) and any native mounting.
- `apps/mobile/vitest.config.ts` now sets `environment: 'node'`, `include: ['src/**/*.test.ts','src/**/*.test.tsx']`, `setupFiles: ['./src/test-setup.ts']`.
- Tried and rejected: `react-test-renderer@19.1.0` — installed, but `toJSON()` returns null and `.root` throws "unmounted test renderer" under React 19 concurrent mode; removed it.

Components are therefore **presentational** (reducer owns state; containers pass `(state, dispatch, t)`). This is verified by a smoke render (8/8 mobile tests pass; typecheck clean). `react-test-renderer` dependency removed; `@types/react`/`typescript` remain.
