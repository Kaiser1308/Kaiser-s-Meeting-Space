2. Native finalized a durable chunk: `index=0`, `bytes=2072576`, `durationMs=21252`.

4. No native event-emission failure or JS event-rejection log was present in the filtered logcat capture.

## Root cause and fix

The Android native module is itself an Expo SDK 54 `EventEmitter`. The JS adapter constructed a detached emitter instead of subscribing to the module instance, so `sendEvent("onChunk", ...)` never reached `RecordingService`. The adapter now uses the `requireNativeModule("AudioRecorder")` instance directly. The native stop path also waits for capture/writer queues before closing the chunk and marshals native events to the main looper.
