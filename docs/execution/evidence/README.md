# Phase Evidence

Create one directory per executed phase: `docs/execution/evidence/Pxx/`.

Each directory contains an `EVIDENCE.md`, one or more timestamped `RUN-YYYYMMDD-HHMM.md` records, and links to machine-readable reports. Do not commit secrets, meeting content, raw audio, transcript, minutes, signed URLs, or personal device identifiers. Large binary reports belong in the approved artifact store with an immutable reference and checksum.
