## Scope

P19-T07 persistent editor journal reload/acknowledgement regression only.

## Root cause and fix

`PersistentEditorJournal.load()` returned a restored journal to its caller but
left the instance's internal journal empty. An acknowledgement sent after an
application reload therefore failed with `acknowledgement mismatch`. The
instance now adopts the restored journal before returning; invalid/no-pointer
loads reset the instance to a fresh bounded journal.
