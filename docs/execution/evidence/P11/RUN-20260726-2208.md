## Environmental Learnings & Workarounds

- **Visual Studio Build Tools vs. GNU Toolchain:**
  - Installing full Visual Studio Build Tools via winget in background sandbox environments can trigger silent UAC blockages (Exit code: 1602).
  - To work around this, we switched the Rust default toolchain to `stable-x86_64-pc-windows-gnu` and installed `RubyInstallerTeam.RubyWithDevKit.3.3` which includes a complete MSYS2/MinGW utility kit (with `gcc`, `ld`, and `dlltool.exe`) added to the system path.
  - This allowed compiling the Rust workspace and testing all P07/durability adapters successfully without any dependency on standard Windows MSVC build tools or `link.exe`.
